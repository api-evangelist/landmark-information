# Landmark Information Group

> UK property and land data business, part of DMGT, that sits in the middle of the residential and commercial property transaction. Landmark aggregates 700+ datasets from nearly 400 suppliers — Ordnance Survey mapping and AddressBase/UPRN addressing, environmental, flood and mining risk, historical maps, planning applications and Barbour ABI project data — and sells them as conveyancing search reports, estate agency compliance products, case management software for property lawyers, and lender and surveyor valuation infrastructure. Its API surface is the Landmark Cloud Services platform: five publicly documented OpenAPI 3.x contracts covering compliance ordering, panel conveyancing, legal case management, contract pack document exchange and valuation milestone webhooks, plus an HTML-documented Planning API.

Reading the contracts is open to anyone; calling them is not. Every Landmark Cloud Services API is OAuth 2.0 client credentials against Landmark's Auth0 tenant, with a client ID and secret issued only after a commercial account is onboarded. UAT and production are separate hosts, separate Auth0 tenants and separate credentials. There is no self-service signup, no free tier and no interactive console.

## APIs

- [Landmark Order Experience API (Compliance)](https://www.landmarkcloudservices.com/?api=order-experience-api): Place and retrieve compliance product orders — AML individual and company, UK and international AML with facial recognition, Persons with Significant Control, Landmark Ownership Check, Scottish Title Check, Source of Funds Check, Identity Verification Check. v1.3.1, base https://api.landmarkcloudservices.com/connect
- [Landmark Conveyancing Experience API](https://www.landmarkcloudservices.com/?api=conveyances-experience-api): Quote for, instruct and manage panel conveyancing work through Landmark Optimus against one shared case record. v0.8.1, base https://api.landmarkcloudservices.com/conveyances
- [Landmark Intelliworks APIs](https://www.landmarkcloudservices.com/?api=intelliworks-experienceapi-CreateCase-api): Create and update cases in the Intelliworks legal case management system from outside its UI, across ten conveyancing and private-client workflows. v2.3.0, base https://api.landmarkcloudservices.com/
- [Landmark Document Vault API (Contract Pack Vault)](https://www.landmarkcloudservices.com/?api=document-vault-experience): Build a secure, shareable container of transaction documents; files are virus-scanned and AI-analysed asynchronously. v1.0.1, base https://api.landmarkcloudservices.com/document-vaults
- [Landmark Milestone Notification Service API](https://www.landmarkcloudservices.com/?api=milestone-service-api): Register, update and delete callback URLs for valuation transaction milestones on the Secure Panel Network. This is Landmark's webhook subscription surface. v1.0.0, base https://api.landmarkcloudservices.com/valuation-spn/milestones/callbacks
- [Landmark Planning API (powered by Barbour ABI)](https://www.landmark.co.uk/products/planning-api/): UK and Republic of Ireland planning applications from 2017 with historical project data back to 1997, 19 attributes including UPRN, easting/northing, latitude/longitude and GeoJSON/WKT site boundaries. HTML documentation only, base https://api.barbour-abi.com/v4
- [Landmark Geodata Web Map Tile Service](https://www.landmark.co.uk/products/web-map-tile-service-0/): OGC WMTS raster mapping tiles, 20 zoom levels from Ordnance Survey MasterMap to national scale. No public endpoint or GetCapabilities document.

## Conventions and operations

- [API conventions](https://raw.githubusercontent.com/api-evangelist/landmark-information/refs/heads/main/conventions/landmark-information-conventions.yml): JSON over HTTPS, multipart uploads, W3C traceparent in and traceresponse out, OData-style $top/$skip/$filter/$orderby on Conveyancing lists only, no idempotency key, async 202 writes polled by transaction id.
- [Error catalogue](https://raw.githubusercontent.com/api-evangelist/landmark-information/refs/heads/main/errors/landmark-information-problem-types.yml): application/problem+json with Landmark members status/code/title/messages, and a shared 5-digit error-code registry (40001 validation, 40100 invalid identity, 40300–40306 entitlement, 40900 conflict, 41000 gone, 42900 rate limit, 50000 server).
- [Rate limits](https://raw.githubusercontent.com/api-evangelist/landmark-information/refs/heads/main/rate-limits/landmark-information-rate-limits.yml): 1,000 calls/min per caller on Document Vault, 250 requests/min per customer on Milestone Service, no limit published for the other three, no rate-limit headers.
- [Lifecycle](https://raw.githubusercontent.com/api-evangelist/landmark-information/refs/heads/main/lifecycle/landmark-information-lifecycle.yml): semantic version per API, declared only in the spec; no deprecation policy, no Sunset header, no status page.
- [Changelog](https://raw.githubusercontent.com/api-evangelist/landmark-information/refs/heads/main/changelog/landmark-information-changelog.yml): dated version histories published inside three of the five API documents.
- [Sandbox](https://raw.githubusercontent.com/api-evangelist/landmark-information/refs/heads/main/sandbox/landmark-information-sandbox.yml): full UAT environment on uat-api.landmarkcloudservices.com, separate credentials, no magic test values, no interactive console.
- [Webhook catalogue](https://raw.githubusercontent.com/api-evangelist/landmark-information/refs/heads/main/asyncapi/landmark-information-webhooks.yml): nine typed valuation milestone notifications plus an order status callback; no AsyncAPI document is published.
